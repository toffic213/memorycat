# 记忆喵

SillyTavern 的独立 API 记忆插件。

当前版本提供：

- 顶栏原生 drawer 入口
- 大总结、小总结
- 角色、物品、世界设定表格
- 手动总结和批量填表
- 自动总结和自动批量填表
- 实时填表提示词注入
- 自动跳过酒馆已隐藏楼层
- 自动收纳旧楼层
- 独立 OpenAI Compatible API
- 聊天级记忆保存
- `{{MEMORY}}` 等变量预览和宏注册

## 使用

1. 打开酒馆顶栏最右侧的记忆喵按钮。
2. 在“设置”中填写独立 API 的 Base URL、Key 和模型。
3. “总览”首页集中设置自动总结频率，并在“批量填表 / 实时填表”中二选一。
4. 在“总览”中选择楼层范围，再执行小总结、大总结或批量填表。
5. 总结草稿会先进入编辑确认；自动总结则按首页自动化设置直接保存。
6. 自动表格更新在关闭“自动写入表格”时会进入“待确认更新”，可稍后应用或丢弃。
7. “楼层收纳”可选择只保留最近 N 个可见楼层，或在大小总结后隐藏已总结楼层；两种模式互斥。
8. 在预设、系统提示词或其他支持宏的位置使用下列变量。

## 变量

| 变量 | 内容 |
| --- | --- |
| `{{MEMORY}}` | 大总结、小总结和全部表格 |
| `{{MEMORY_SUMMARY}}` | 大总结和小总结 |
| `{{MEMORY_BIG}}` | 仅大总结 |
| `{{MEMORY_SMALL}}` | 仅小总结 |
| `{{MEMORY_TABLES}}` | 三类表格合并 |
| `{{MEMORY_CHARACTERS}}` | 角色表格 |
| `{{MEMORY_ITEMS}}` | 物品表格 |
| `{{MEMORY_WORLD}}` | 世界设定补充 |

实时填表只会在正文生成提示词中追加独立的更新格式；解析成功后会从最终正文中移除，不会把内部标签留在聊天里。批量填表和实时填表是互斥工作模式，不会同时运行。

记忆喵默认不会把酒馆已隐藏楼层送去总结。自动收纳只会把楼层标记为酒馆原生隐藏状态，不会删除聊天内容。

插件目录：

```text
data/<user>/extensions/memory-cat/
```

计划书位于：

```text
data/default-user/extensions/toolsforme/记忆喵-计划书.md
```
